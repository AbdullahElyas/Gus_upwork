Part 1 – Set Up Google Cloud & Sheets API

This gives the tool permission to read data from your Google Sheets. At the end of this part you will have a file called credentials.json.

A. Create a Google Cloud Project

1 Go to the Google Cloud Console

Open your web browser and go to:
https://console.cloud.google.com/

Sign in with your Google account (the same one you use for Google Sheets).

2 Create a new Project

At the top of the page, click the project dropdown (it may say "Select a project" or show an existing project name).

Click "New Project" in the top-right of the popup.

  • Project name: Enter something like BiomechReports
  • Organisation: Leave as default (or "No organisation")

Click "Create". Wait a few seconds, then select your new project from the dropdown.

B. Enable the Required APIs

3 Enable Google Sheets API

Go to:
https://console.cloud.google.com/apis/library/sheets.googleapis.com

Make sure your new project is selected at the top, then click the blue "Enable" button.

4 Enable Google Drive API

Go to:
https://console.cloud.google.com/apis/library/drive.googleapis.com

Click "Enable".

C. Create a Service Account & Download credentials.json

5 Open the Service Accounts page

Go to:
https://console.cloud.google.com/iam-admin/serviceaccounts

Make sure your project is selected at the top.

6 Create a Service Account

Click "+ Create Service Account" at the top.

  • Service account name: biomech-api (or any name you like)
  • Service account ID: This fills in automatically

Click "Create and Continue".

On the next screen ("Grant this service account access"), you can click "Continue" without selecting a role (it is not needed).

On the final screen, click "Done".

7 Create and download the JSON key file

You should now see your service account in the list. Click on its email address (e.g. biomech-api@biomechreports.iam.gserviceaccount.com).

Go to the "Keys" tab at the top.

Click "Add Key" → "Create new key".

Select "JSON" and click "Create".

A file will download to your computer — it will be named something like biomechreports-abc123.json.

Save this file! This is your credentials.json. You will copy it into the tool's folder in Part 3.
Keep this file private! Anyone with this file can access the Google Sheets shared with this service account. Do not share it publicly or post it online.
8 Note the service account email address

Write down (or copy) the service account's email address. It looks like:
biomech-api@biomechreports.iam.gserviceaccount.com

You will need this in Part 4 to share your Google Sheets.

Part 2 – Set Up OpenAI Account & API Key

The tool uses OpenAI's GPT models to generate the written assessment text. You need an OpenAI account with a small amount of credit loaded.

A. Create an OpenAI Account

1 Go to the OpenAI Platform

Open your browser and go to:
https://platform.openai.com/signup

Sign up with your email address (or use Google / Microsoft sign-in).

Follow the prompts to verify your email and complete registration.

B. Add a Payment Method & Set a Budget

2 Go to Billing Settings

Once logged in, go to:
https://platform.openai.com/settings/organization/billing/overview

Or click your profile icon (top-right) → "Settings" → "Billing" in the left sidebar.

3 Add a payment method

Click "Add payment details".

Choose "Individual" (unless you are a company).

Enter your credit/debit card details and billing address.

Click "Continue".

4 Add credit to your account

You will be asked how much credit to add. Enter $10 (US dollars).

This is enough to generate hundreds of reports. A single report costs roughly $0.01 – $0.03.

Click "Continue" and confirm the payment.

5 Set a monthly spending limit (recommended)

On the Billing page, look for "Limits" or "Usage limits".

Set the monthly budget to $10. This prevents unexpected charges.

You can also set a notification email alert at e.g. $5 so you know when you are halfway through.

With a $10 budget, you can generate approximately 300–500 full reports before needing to top up.

C. Create an API Key

6 Go to API Keys page

Go to:
https://platform.openai.com/api-keys

Or from the left sidebar: "API Keys".

7 Create a new API key

Click "+ Create new secret key".

  • Name: biomech-tool (or anything you like)
  • Permissions: Leave as default ("All")

Click "Create secret key".

8 Copy and save your API key

A key will appear that starts with sk- followed by a long string of characters.

IMPORTANT: Copy this key immediately and paste it somewhere safe (e.g. a text file on your desktop). You will NOT be able to see it again after closing this window.

Example format: sk-proj-AbCdEf123456789...

Keep your API key secret! Anyone with this key can use your OpenAI credit. Never share it publicly.

Part 3 – Add Your Credentials to the Tool

Now you will place your Google and OpenAI credentials into the tool's folder so it can use them.

A. Replace credentials.json

1 Find the tool's folder on your computer

Open File Explorer and navigate to the folder where the tool is installed (the folder containing files like report_generator.py, textllm.py, etc.).

2 Replace credentials.json

In the tool's folder, you will see a file called credentials.json.

  • Delete (or rename) the existing credentials.json.
  • Copy the JSON key file you downloaded in Part 1 (Step 7) into this folder.
  • Rename it to exactly: credentials.json
The file must be named exactly credentials.json (all lowercase). If it has a different name, the tool will not find it.

B. Update the .env File with Your OpenAI Key

3 Find the .env file

In the same tool folder, look for a file called .env

Note: This file starts with a dot, so it may be hidden. In File Explorer, click View → tick "Hidden items" to make it visible.

4 Edit the .env file

Right-click the .env file → "Open with" → "Notepad".

You will see a line that looks like:

OPENAI_API_KEY=sk-old-key-here...

Delete everything after the = sign and paste your new API key from Part 2 (Step 8).

The line should now look like:

OPENAI_API_KEY=sk-proj-YourNewKeyHere...

Save the file (Ctrl+S) and close Notepad.

Make sure there are no spaces before or after the = sign, and no quotation marks around the key. The format must be exactly: OPENAI_API_KEY=sk-...

Part 4 – Share Your Google Sheets

The tool accesses your Google Sheets through the service account you created. You must share each sheet with the service account email.

1 Open your Google Sheet in your browser

Go to https://sheets.google.com and open the spreadsheet you want to generate a report from.

2 Click "Share"

Click the green "Share" button in the top-right corner of the sheet.

3 Add the service account email

In the "Add people" field, paste your service account email address from Part 1, Step 8.

It will look something like: biomech-api@biomechreports.iam.gserviceaccount.com

Set the permission to "Editor" (so the tool can read and write data).

Uncheck "Notify people" (the service account cannot receive emails).

Click "Share".

You need to do this for every Google Sheet you want to generate reports from. If you have a shared Google Drive folder, you can share the entire folder with the service account email instead — all sheets inside will then be accessible.

Part 5 – Test Everything

1 Verify your setup

Make sure you have:

  • ☐ Your credentials.json in the tool folder (from Part 1)
  • ☐ Your .env file updated with your OpenAI API key (from Part 2)
  • ☐ Your Google Sheet shared with the service account email (from Part 4)
2 Run the tool

Run the report generation tool as normal. If everything is set up correctly, it will:

  • Connect to your Google Sheet and read the assessment data
  • Generate the written assessments using OpenAI
  • Produce the final HTML/PDF report

Troubleshooting

Problem Solution
"credentials.json not found" Make sure the file is named exactly credentials.json and is in the same folder as report_generator.py.
"Permission denied" or "Sheet not found" Share the Google Sheet with the service account email (Part 4). Check you copied the email correctly.
"Invalid API key" or "Authentication error" from OpenAI Open the .env file and check the API key is correct with no extra spaces. Make sure it starts with sk-.
"Insufficient quota" or "Rate limit" Your OpenAI credit may have run out. Go to https://platform.openai.com/settings/organization/billing/overview and add more credit.
"Google Sheets API has not been enabled" Go back to Part 1, Steps 3–4 and make sure both APIs are enabled for your project.
